# FastAPI Todo App

A basic Todo Application built with FastAPI that demonstrates REST API development, JWT-based authentication, SQLAlchemy database integration, and request/response validation using Pydantic.
 Features

    FastAPI Routing – Organized API endpoints for managing todos.
    JWT Authentication – Secure authentication using JSON Web Tokens.
    SQLAlchemy Integration – Database operations using SQLAlchemy ORM.
    Pydantic Validation – Request and response data validation.
    CRUD Operations – Create, read, update, and delete todos.
    RESTful API – Clean and structured API endpoints.
    Interactive API Documentation – Explore and test endpoints using Swagger UI.
